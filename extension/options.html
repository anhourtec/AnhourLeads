Save person options

Connect the extension to your workspace with an API key. Create one in Settings → API keys.

The address you use to sign in, for example https://acme.example.com or http://acme.localhost:3410.

Stored only in this browser profile. The key's role decides what the extension may do.

What the extension does and does not do:

  • It reads the page only when you click its toolbar button, and only the page in front of you.
  • It saves at most one person per page, after you review the details, into your own workspace.
  • It never opens other pages, scrolls, clicks, or reads lists or search results.
  • You are responsible for following each website's terms when you save someone from it.
